# Análise de Dados de Vendas com SQL

## Descrição do Projeto

Este projeto tem como objetivo realizar uma análise exploratória e analítica de dados de vendas utilizando SQL, com foco na identificação de padrões de desempenho, lucratividade e comportamento de vendas por categoria e produto.

A análise busca apoiar a tomada de decisão por meio de métricas relevantes de negócio, como faturamento, lucro e ranking de performance.

## Objetivos da Análise

Avaliar o desempenho de vendas por categoria e produto

Identificar produtos mais lucrativos e com maior volume de vendas

Analisar a relação entre faturamento e lucratividade

Explorar padrões que possam indicar oportunidades ou riscos de negócio

## Fonte de Dados

Os dados utilizados representam registros de vendas contendo informações como:
Categoria do produto
Nome do produto
Volume de vendas
Lucro
Preço e métricas financeiras associadas
(Base utilizada para fins educacionais e analíticos.)

## Ferramentas e Tecnologias

SQL
CTEs (WITH)
Funções de agregação
Funções de janela (RANK() OVER)
Jupyter Notebook para organização das análises e documentação dos resultados

## Principais Análises Realizadas

Ranking de produtos por volume de vendas e lucratividade
Comparação de desempenho entre categorias
Identificação de produtos com alto faturamento e baixa margem
Tratamento de dados nulos para garantir a integridade da análise

## Principais Insights

Algumas categorias apresentam alto volume de vendas, porém margens de lucro inferiores à média.
Determinados produtos, mesmo com menor volume, demonstram maior eficiência em termos de lucratividade.
O tratamento adequado dos dados foi essencial para evitar distorções nas métricas analisadas.

## Conclusão

A estruturação e o tratamento das consultas SQL foram fundamentais para garantir a integridade da base de dados, possibilitando análises mais consistentes e a geração de insights relevantes sobre o comportamento de vendas, apoiando decisões estratégicas de negócio.
